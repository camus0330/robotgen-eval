# 统一任务书 v0.1（预跑版）

## 研究问题与边界

比较在同一输入、工具及预算条件下生成可重建机器人设计与控制方案的能力。仅针对本8自由度形态及两项动作；不外推到任意机器人，不声称实机可靠度或制造认证。

本轮为 `joint_design_and_control`。结构、参考动作、控制方案都由参评模型产生；必须同时交付。若后来固定控制器只比较结构，应另建实验，不混合排名。

## 固定要求

- 电机：8台 XL330-M288-T，原厂STEP由输入包提供。不混用纪要另一个模块提及的XC330。
- 左右肩、肘、髋、膝各1个pitch关节，无主动腕踝。语义关节与角度范围以 `motion_profile.json` 为准。
- 外部5V供电，自由基座；不允许悬吊、root位置伺服、隐形支撑或在运行中回写root轨迹。
- 世界坐标：+X向前、+Y向左、+Z向上。CAD单位mm；动力学m/kg/s/rad。pitch正方向统一绕+Y，局部坐标转换必须明确。
- 单件打印包络220×220×250mm；不限定零件数量、文件名、肢段长度或叉架形状。
- 材料初筛假设：PETG承力件，密度1.27g/cm³、局部计算许用应力8MPa；TPU接触垫密度1.20g/cm³；属于本实验建议值，需预跑后统一冻结，不是材料实测。
- 电机及采购件质量统一资料来源并写入BOM；附件合计35g，必须给出安装位置和所属link。不得通过漏算附件改善动力学。
- 仿真2ms步长，控制25Hz；动作记录间隔40ms，驱动峰值和饱和比例按全部2ms步计算。控制增益/参考轨迹在扰动测试前冻结。
- 时间上限：前荡16s、挥手15s。两项动作结束均须稳定落地。

## 动作成功判据

| 项目 | 必须满足 |
|---|---|
| 前荡 | 双掌真实接触力均>0.01N；双后足不接触且离地>2mm连续≥0.5s；同一窗口内前进≥10mm；动作结束相对起点前进并落稳 |
| 挥手 | 左掌离地>50mm，另三垫接触力各>0.01N，连续≥1s；该窗口左肩与左肘各变化≥0.1rad；最后落稳 |
| 落稳 | 四垫接触力各>0.01N、up_z>0.95、线速<0.02m/s、角速<0.2rad/s，尾段连续≥1s |
| 支撑限制 | 不得由接触垫以外部位撑地；不得用关节限位反力代替驱动 |
| 跟踪 | 最大关节误差≤5°、最大root参考误差≤5mm；root参考只用于测量，不驱动基座 |
| 驱动 | 峰值力矩≤0.100001N·m、饱和采样比例≤0.1%、限位支撑力矩≤0.001N·m |
| 关节 | 实际动作距上下限的最小裕量≥1° |

以上数值继承现有项目门槛，属于试行阈值。`motion_profile.json` 的旧版本标识只表示数值来源；本实验身份由 `protocol.json` 确定。

## 交付与评价

必须提交可修改CAD源码、全部打印件STEP/STL、装配STEP、BOM、MJCF、URDF、两项动作参考与控制源码、重建入口、说明、限制声明和设计映射。原始模型对话与身份由实验操作者另外保存。

权重暂沿用CAD与数字装配30、运动与任务35、工程数字初筛20、复现与审计15。零件数量固定、特定叉架探针及20个固定结构案例等规则需泛化；泛化后的评测必须另定版本并对全部方案重跑。旧版指标文件在输入包中命名为 `legacy_metrics_reference.csv`，仅供门槛来源参考，不能优先于本任务书的形态自由度。

扩展数字装配的公差链、完整工具路径、全部紧固件、切片支撑、完整BOM干涉、连续扫掠、全机载荷路径、线缆包络单独报告覆盖状态。没有实物不扣核心分，也不把未知项写成通过。
