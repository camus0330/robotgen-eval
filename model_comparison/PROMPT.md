# 机器人结构与控制联合设计任务

你需要根据本输入包从零生成8自由度机器人设计和控制方案，并在本次分配的时间、工具与反馈预算内完成交付。

请先阅读 `TASK_SPEC.md`、`SUBMISSION_SPEC.md`、`protocol.json` 和 `motion_profile.json`。以 `assets/reference.png` 为形态参考，以 `assets/xl330_m288_t.step` 为统一电机输入。不要假设存在其他模型的答案或原始机器人源码。允许不同的零件拆分、文件名与尺寸；必须满足规定的电机、自由度、动作、驱动及单位约束。

请在独立 `submission/` 目录中：

1. 编写可重建的CAD与仿真/控制源码，导出装配STEP、各打印件STEP/STL、BOM、MJCF、URDF，以及前荡、挥手的参考轨迹和控制配置。
2. 填写 `design_manifest.json`，准确描述所有打印零件、八个语义关节、四个接触垫、每个电机的机壳/horn安装接口及坐标变换。不要用固定模板中的空对象冒充完整设计。
3. 提供命令数组形式的重建入口和完整依赖声明；在说明中列出运行步骤、材料及质量假设、碰撞检查范围、局部结构计算方法和未解决问题。
4. 对实际完成的验证保存原始结果。没有完成的任务明确标注；不要编造得分、工程验证或实测数据。
5. 初次交付后只能按操作者给出的标准化反馈修复；所有修复仍计入总预算，保留初次与最终版。禁止读取评测方隐藏资料或修改评测代码。

最终给出文件目录、重建命令和已知限制。模型版本、耗时、费用和原始对话日志由操作者核实填写，未知时保持null，不猜测身份。
