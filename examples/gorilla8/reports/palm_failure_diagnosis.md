# 双掌前荡失败诊断：原横向圆柱掌垫

结论：当前失败是**前后支撑裕量接近零、实际姿态偏离参考，以及肘部承载力矩余量不足共同作用**。实际 COM 在计划抬足前越过最前接触边界，后足承载随后消失，机器人绕仍然承重的双掌快速前倾。证据不支持把原因归为“手掌先失去法向支撑”或“地面摩擦先耗尽”；也不能只归为 PD 参数问题。有限前后尺寸的平底掌面与前臂竖直的新参考值得重新设计，但本报告不把该假设计为通过。

## 数据与方法

- 原始结果：[palm_swing_final_cad_gravity_ff_pitch/result.json](../output/simulation_runs/palm_swing_final_cad_gravity_ff_pitch/result.json)。对应 `trace.json` 共 225 帧，0–8.96 s。
- 参考：[palm_swing/poses.json](../output/motions/palm_swing/poses.json)，450 帧，计划 17.96 s。参考的双足腾空阶段从 9.56 s 开始。
- 模型质量 0.5220157988653644 kg，重力 9.81 m/s²，总重 5.12098 N；自由基座，8 个 pitch 执行器，各限幅 ±0.10 N·m。2 ms physics，25 Hz 目标更新。
- 使用原运行的准静态力矩前馈与正恢复方向肩部反馈，**没有改 PD、参考、质量、摩擦、碰撞体或力矩上限**。为取得原 trace 未保存的法向力，按同一初始状态、1 s 稳定段、控制更新顺序确定性重放；225 个采样帧全部 qpos 与保存 trace 的最大绝对差为 **0.0**。
- COM 和接触点来自对应实际 qpos 的 `mj_forward`；法向力来自重放状态的 `mj_contactForce`，作用于掌/足的世界力按接触 frame 转换。接触法向力是仿真量，不是真实 TPU 压力测量。
- 力矩饱和比例使用重放的全部 **2 ms** 执行器力样本。25 Hz trace 恰好在目标更新后的采样边界，不能把连续的限幅采样帧直接解释为区间内每一步均饱和。

本次只分析既有失败，不进行新的参数试验；未修改最终 CAD、模型、源代码或已有报告。

参考在 8.56 s 仍把 COM 放在 X=50.780 mm、前掌接触线 X=55 mm，理论前边界余量 4.220 mm；实际掌中心已滚移到约 X=63.2 mm，实际 COM 则到 X=63.993 mm。两者都前移，但 COM 的前移更大。此时关节最大偏差仅约 1.405°，已经足以消耗剩余几毫米支撑裕量。不能以“关节角看起来跟得上”替代浮动机身的平衡检查。

## 双掌仍承重；前后可用接触区域过窄

MuJoCo 使用半径 12 mm、横向 Y 轴的完整圆柱掌垫，`condim=3`，滑动摩擦 0.8。每个圆柱形成横向接触线；没有独立的接触转矩自由度。两手横向分开提供左右支撑，但不等于存在足够的前后支撑区域。

| t / s | 左掌 Fz / N | 右掌 Fz / N | 后足总 Fz / N | base pitch rate / rad·s⁻¹ |
|---:|---:|---:|---:|---:|
| 8.40 | 2.445 | 2.453 | 0.678 | 0.0269 |
| 8.60 | 2.597 | 2.595 | 0 | 0.0927 |
| 8.68 | 2.510 | 2.513 | 0 | 0.4442 |
| 8.80 | 2.340 | 2.341 | 0 | 2.4467 |
| 8.92 | 1.500 | 1.500 | 0 | 8.1832 |

这些掌接触的法向均为世界 +Z。8.68 s 两掌全部接触点 X 只覆盖 **63.892–64.069 mm，跨度 0.177 mm**；COM 已在 X=70.504 mm。掌的正常承载没有先消失，倾倒发生在仍有法向承载的滚动接触上。

8.68 s 掌接触的切向力/法向力比最大约 0.107，8.80 s 约 0.188，均显著小于设定摩擦系数 0.8。这些关键样本没有显示先碰到摩擦锥边界。掌中心逐步前移不应一概称为“打滑”；圆柱自身允许滚动。

计划在 9.56 s 令 COM 精确落在 X=55 mm 的双掌接触线上，参考静力解存在，但前后支撑维度退化。这样的静力解没有位置扰动裕量，不能证明动态可跟踪。主动关节控制仍可能改变 COM 和角动量，因而不能从本次失败推出所有控制器均不可能成功。

## 力矩不足是实际参与因素

参考 9.56 s 每掌承重约 2.5605 N，两肘静态需求约 **−0.098595 N·m**；全部参考帧峰值 **0.099115 N·m**，距设定 0.10 N·m 上限仅 **0.000885 N·m（0.885%）**。这还没有给加速度、关节摩擦、跟踪误差和扰动恢复留出可观余量。

此时前臂相对全局竖直方向约倾斜 33.73°，掌法向力相对肘轴存在较大的水平力臂。前臂竖直的新参考可减少这一法向力力臂，具体改善仍须按新质量、真实掌面 CoP 和全链反力重新求解。

| 重放区间 / s | 左肘力矩饱和比例 | 右肘力矩饱和比例 | 肩部情况 |
|---|---:|---:|---|
| 7.08–8.00 | 0% | 0% | 无执行器饱和 |
| 8.00–8.52 | 15.77% | 21.15% | 两肩均未饱和 |
| 8.52–8.68 | 43.75% | 45.00% | 两肩均未饱和 |
| 8.68–8.96 | **92.86%** | **92.86%** | 两肩各约 7.14% 饱和；肩目标修正已达到设定边界 |

因此不能说“只要增大 PD 就能稳住”：肘部在失稳阶段已大量受到真实力矩裁剪。也不能说“电机必然完全带不动所有双掌姿态”：现参考力臂较差，换支撑面和参考姿态可能改变所需关节力矩。

## 对平底前掌方案的含义

1. 双掌需要形成有非零前后尺寸的实际支撑矩形，能够通过压力分布移动 CoP。仅把侧面造型加宽而仍用圆柱/单线接触仿真，无法验证该机制。
2. 在双足悬空阶段保持前臂全局竖直，有助于维持掌底水平并降低肘部法向反力的水平力臂。躯干沿上臂圆弧运动时，必须同时检查整个阶段的 COM、可用 CoP、动态力矩与落足条件。
3. 当前失稳瞬间需要的前方支撑不能直接被“后伸 45 mm”替代：新设计必须把**新的** COM 轨迹放入其整个支撑矩形内，并留误差裕量。当前 8.56 s 前超 0.70 mm、8.68 s 前超 6.43 mm 仅说明旧系统如何出界，不能用倾倒后的几十毫米偏差直接定掌尺寸。
4. 新增掌面会增加质量、惯量和地面碰撞约束，还可能改变抬掌/挥手时的净空。临时零质量平底碰撞体最多用于物理机制对照，不能作为最终 CAD 或制造通过证据。

独立实际 CAD 轨迹检查见 [simulation_palm_swing_collision.json](simulation_palm_swing_collision.json)：225 帧没有内部自交，但最后一帧右上臂穿地约 37.803 mm，地面检查失败；这也与保存视频中的前倾跌倒一致。当前动力学地面碰撞体是近似形状，完整 CAD 掌垫变形和真实接触压力分布尚未建模。
