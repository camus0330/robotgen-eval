# 运动校核迭代记录

此文件保留失败和设计变更背景，不代表最终结果。当前交付参考是 `output/motions/flat_palm_swing/` 和 `flat_palm_wave/`，两目录各自保存 `design_used.json`、`masslinks_used.json` 和 `report.json`。`output/motions/` 根目录的旧质量快照属于圆掌迭代，不能当作平掌输入。

## 首轮真实质量校核的失败

命令：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python examples/gorilla8/src/plan_motion.py --mass-file examples/gorilla8/reports/masslinks.json
```

首次质量约 0.54455 kg，采用旧后腿 `42+52 mm`、髋位置 `(-20, ±42, -52) mm`。

- 所有帧竖直接触力平衡有解。
- 支撑推进最低点接触裕量 11.025985 mm；换手期间远侧后膝峰值 0.105415 N·m，48 帧超过 0.10 N·m 目标。
- 挥手最低裕量 8.589184 mm；远侧后膝峰值 0.100411 N·m，141 帧超过 0.10 N·m 目标。
- 进程退出码 **2**，由脚本对静态载荷超标显式返回；不是 Python 异常或动力学运行失败。

后续升高换手身位及调整挥手后移量，并使用减重后的 CAD 质量模型，旧几何曾达到所有采样帧的竖直静力目标。这些结果只对应当时几何，不能迁移到重新设计的腿部。

## 腿部机械布局变更

机械装配检查发现旧 42 mm 大腿无法容纳 U 叉桥与膝机身，主设计将腿上段改为 **55 mm**，下段保持 **52 mm**；髋改为 `(-20, ±52, -33) mm`。新中立 root 高度 137 mm、手接触圆心 `(55, ±56, 12)`、脚圆心 `(-40, ±52, 12)` 对应：

- 肩/肘：约 `(-35.246°, 34.963°)`；
- 髋/膝：`(39.779297°, -56.764818°)`。

新几何首次只运行无质量文件的运动学检查，输出 `output/motions_new_leg_kinematics/`，退出码 0。全部采样关节满足限位且所需接触位置可达，但这一步没有使用旧质量文件，静态结果明确为 pending。后续必须配套新 CAD 质量重算正式 `output/motions/`。

双掌托体扫描始终只生成一帧静态候选：CoM 位于双掌接触中心连线上，前后点接触裕量为零，进入/离开、碰撞、动态前荡和硬件表现未由该扫描证明。

这些数字是参考运动学计划，不是自由基座中实际发生的位移或接触证据。脚本生成退出码 0，已交由独立 CAD 碰撞与自由基座 MuJoCo 检查；最终应读取对应独立报告，不能从本记录推断动态完成。
