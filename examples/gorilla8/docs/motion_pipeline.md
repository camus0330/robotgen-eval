# 平掌参考运动与静态校核

正式入口为 `src/plan_flat_palm_motion.py`，读取 `design.py` 及实际 CAD 导出的 `reports/masslinks.json`，输出 `flat_palm_swing` 与 `flat_palm_wave`。其他规划脚本保留为旧圆掌诊断及共用 IK/导出函数，不应重新生成旧动作作为当前设计验收。

```bash
.venv/bin/python examples/gorilla8/src/plan_flat_palm_motion.py
```

默认前荡终肩角 +10°，可用 `--end-shoulder-deg` 指定，但仍须独立通过限位、静力、碰撞和自由基座检查。脚本本身不与硬件通信。前掌长度65mm、宽34mm、底面相对末端中心z=-12mm，参数来自设计契约；没有腕轴。

## 文件与坐标

两个动作目录分别保存：

- `motion.npz`：time_s、joint_pos_rad、joint_names、root_pos_m、root_quat_wxyz、contact_mask、end_center_m、reference_fps。
- `poses.csv`：逐帧阶段、root毫米、关节度数、接触标志。
- `poses.json`：同帧参考姿态、实际FK端点、准静态法向力/压力中心/力矩与支撑裕量。
- `report.json`：数据契约、残差、静态目标及未验证层。
- `masslinks_used.json`、`design_used.json`：该次实际使用的质量及几何参数。

世界X前、Y左、Z上；joint正轴全部+Y。顺序固定为左肩、左肘、右肩、右肘、左髋、左膝、右髋、右膝。JSON/CSV几何使用mm，NPZ位置使用m、关节使用rad、root四元数wxyz。解析参考root无旋转，初始root x=y=0，地面z=0。没有外部视频、mocap来源FPS、重定向或缩放；参考采样25Hz。仿真timestep、decimation及实际root见simulation.md，不能把参考root当成动力学结果。

质量文件为9个link的映射，每项包含mass_kg、com_mm与明细，COM在该link局部坐标系。源电机按真实质量分配到stator/rotor，打印件按满实体密度估重，另有明确紧固件、线束及外部供电控制器余量；不含机载电池。

## 动作含义

前荡：从平掌四点站姿依次收起后腿，在双后足同时离地时保持两前掌平底承重，通过肩/肘相反转动将身体向前移，随后依次落足并保持静止。正式阶段包含可观测的双掌独立支撑区间。它是一段有限前荡，未实现反复换掌的循环步态。

挥手：保持另一掌与后足支撑，先沿平掌约束向后移重，然后在矢状面抬起左手并做两次前后挥动，恢复接触与中立姿态。没有外展、roll或yaw关节。

支撑前掌保持q肩+q肘=0，前臂相对地面竖直，使真实平底与地面平行。离地手臂可改变此关系，但规划会按平掌实际前/后缘计算最低点，不能继续使用原圆柱中心减半径的近似。

## 静态方法与边界

前掌采用真实矩形四角的非负竖直反力，后足使用圆弧接触中心点。求解整机重力及两个水平力矩平衡，再最小化8关节最大绝对静载力矩；包含各关节下游link自重。双掌同时支撑时，各掌横向CoP约束居中；单掌支撑时允许其横向压力中心在实际宽度内变化。

0.10N·m为持续设计估算上限，0.08N·m是更宽裕的期望值，报告分别记录，不将未达期望写成已达。输出CoP和力分配只表示存在准静态平衡，不能保证位置伺服实现同样分配，也不验证摩擦、冲击、热、粘接或结构变形。

不可达、超限、掌底穿地等错误直接失败。静力无解或超过0.10N·m时保存报告并返回2，方便保留真实失败。返回0也不能代替实际接触、前移、落脚与CAD干涉检查；这些由独立仿真及碰撞报告决定。
