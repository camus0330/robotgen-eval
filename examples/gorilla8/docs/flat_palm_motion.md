# 平底前掌独立运动参考

入口 `../src/plan_flat_palm_motion.py` 使用实际 CAD 的 `reports/masslinks.json`，只生成 `output/motions/flat_palm_swing/` 和 `flat_palm_wave/`。旧圆弧前掌 reference 与失败证据保留，不被该入口覆盖。

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python examples/gorilla8/src/plan_flat_palm_motion.py
```

`--end-shoulder-deg` 指定双掌支撑前移的终点肩角，默认 `10`，必须落在经过独立几何检查的 `design.py` 限位内。最终髋桥、肩梁和上臂内叉经过实体避让修改，肩关节限位为 `[-135,+12]°`、肘关节为 `[-12,125]°`；参考端态 `(+10,-10)°` 与限位仍有 2° 间隙。不得为使脚本运行而放宽限位。

模型从 `design.py` 的 `PALM_X_MIN_MM`、`PALM_X_MAX_MM`、`PALM_WIDTH_MM` 读取前掌尺寸：相对末端圆心 X `[-45,+20] mm`、Y `[-17,+17] mm` 的实际平底矩形，底面为末端圆心下方 12 mm。后足仍为圆弧垫。支撑前掌必须保持全局前臂角 `q_shoulder + q_elbow = 0`；其压力中心可在整个前后矩形范围内变化，不再固定在末端圆心。两掌共同支撑时，将各掌横向压力中心约束在其中心线以避免任意偏载；单掌支撑时允许完整矩形内的横向压力中心变化。

静力线性规划同时满足总重力、俯仰和横滚力矩平衡，所有接触法向力非负，并最小化最大关节力矩。力矩包含对应关节全部远端零件自重。`poses.json` 的 `contact_CoP_xy_mm` 给出每肢实际选用的压力中心；`normal_force_N` 和 `joint_torque_Nm` 可供后续仿真核对，不能从这些静力数值推断动态接触或电机温升。

中立 root 平移设为 x=y=0；肩/肘 `(-10°, +10°)`，root z=147.08846518 mm，手心 `(30.41889066, ±56, 12) mm`，后足 `(-29.58110934, ±52, 12) mm`，髋/膝约 `(21.49543967°, -33.22632387°)`。后足名义轮廓与加长前掌后缘留约 3 mm 的平面间隙，最终仍须以全部实体几何检查为准。

前移参考从四点支撑出发，将后足依次先抬高以避开前掌延长段、向身体后方收起。在两后足离地期间，肩角从 `-10°` 变至 `+10°`、肘角取反，保持前臂竖直，使躯干向前移动 20.8378 mm；髋膝从 `(50,-90)°` 变至 `(60,-100)°`。随后后足经后方过渡点依次落地，最后保留 2.4 秒四点静止观察。当前是单次前移，循环所需的前掌重新落位尚未实现。

挥手参考先四点支撑后移身体，抬起左手时先保持掌面平行直到足够离地，再进行矢状面挥动。放下时先恢复掌面平行，再下降接地，避免直接角度插值令加长前掌后缘扎入地面。末端同样保留 2.4 秒四点静止观察。

输出格式沿用 [motion_pipeline.md](motion_pipeline.md)：25 Hz reference，关节 rad、NPZ root/末端位置 m、JSON/CSV 位置 mm、root 四元数 wxyz、+X 前/+Y 左/+Z 上。source FPS、simulation timestep、control decimation 和 policy frequency 未由该规划入口定义。新目录各自保存 `masslinks_used.json` 和 `design_used.json`，不得与旧圆掌或旧质量报告混用。

0.10 N·m 是本项目保守持续设计目标；0.08 N·m 是预留约 20% 余量的偏好目标。退出码 0 只表示 reference 已生成，采样姿态满足限位/脚垫地面检查、竖直静力有解且力矩不超过 0.10 N·m。报告另外标记是否达到 0.08 N·m。实体碰撞、自由基座双足真正离地前移、完整落脚稳定和硬件试验由独立证据判定。
