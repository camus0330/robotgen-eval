# Gorilla8 样例评测：已有证据支持标称动作，装配与工程验证尚不完整

日期：2026-09-18。评测依据 [benchmark v0.1](README.md)，读取正式 `flat_palm_swing_release` / `flat_palm_wave_release`；新增评分结果见 [scorecard.json](results/gorilla8/scorecard.json)。没有修改被评测模型。

## 结论与分数

**得分下界39/100、可能上界94/100、加权证据覆盖率45%。** 已有证据满足数字提交基本契约及两项标称有限动作。尚不能判断是否无需返工即可实装，更不能认定实机负载、温升、寿命、电气停止合格。

“已验证”包括足以判定失败的证据，因此不是“通过”。11项PASS、2项FAIL、17项UNVERIFIED。未知项未来全部通过才可能达到94；这个上界不是预测。已评项目合格率为86.67%，因覆盖不足不用于排名。当前没有其他AI身份明确且同条件生成的独立提交，不能据此得出模型优劣。

## 本次实际做了什么

- 读取原研究报告、制造/布线/结构说明、正式释放汇总、逐件CAD导出报告、三份正式碰撞报告和局部应力报告；区分历史诊断与正式数据。
- 直接解析当前URDF，核对8个pitch关节顺序、轴、限位、质量及惯量基本物理条件；核对打印BOM与文件数量。
- 从398帧前荡、373帧挥手的原始trace，重新计算连续接触窗口、位移、抬手高度、稳定落地时间、最大/RMS跟踪误差及采样力矩RMS。
- 为实际读取的证据文件和评测代码生成SHA-256清单；对文档版本歧义保留人工复核记录。

CAD导出有效性、碰撞和20例局部强度采用已有报告，本次没有重跑其几何/物理计算。复制的 `.tools/venv` 中包目录为Python3.10，而当前解释器为3.12.3，实际 `import cadquery` 失败。因此不能把现有虚拟环境目录存在算成干净环境可复现；D02为未验证，未因环境迁移失败判定机器人设计失败。benchmark脚本本身不依赖该环境。

B06失败是**新benchmark阈值下的结果**，不表示原报告算错，也不推翻其有限动作完成结论。阈值由本例后验制定，不能据其微小差异作模型能力排名。

其他证据：12种交付零件包含10种正式件共17件及2种试片；已有回读最大STEP体积相对误差约0.000298%，STL约0.574951%，均小于本版0.1%/1.5%门槛。该检查不是跨CAD系统完整产品结构/PMI交换测试。质量账本与URDF均为0.5605794217kg，为估计量而非称重。

三份碰撞报告覆盖参考772帧（含额外中立帧）及实际398/373帧；没有连续帧间检测，未包含新增螺钉、螺母及柔性线束完整实体。B04通过不代表A09/B05通过。当前仿真契约 `self_contact_in_mujoco=false`，完整CAD自碰撞由离线记录帧检查补充，不能理解为动力学引擎已经对全部自接触作出响应。

20个局部截面案例的最小余量为1.1221，相对于假设各向同性PETG许用8MPa；只覆盖声明的局部载荷贡献。它不证明全机强度、刚度、层间、胶接、疲劳或连接件保持力，C02仍未知。

## 影响比较可信度的问题

1. **历史说明未充分标记。** `reports/manufacturing_validation_notes.md` 仍写“最终质量0.5220157988653644kg”和旧版帧数，当前README与release为0.5605794217046942kg。D03失败。早期 `docs/motion_design_review.md` 已明确是设计输入，其0.45kg建议目标不当作当前硬约束来追加失败。
2. **原始生成过程不可识别。** 缺少确定的AI版本、完整提示词、预算、采样和人工修订记录，D04未知。交付副本214个文件与主目录逐字节相同，不是另一个AI的输出。
3. **已有结果尚无完整生成时哈希链。** 本次新增manifest只是快照，不证明旧报告确实由当前全部几何生成。正式run的design、contract对应一致，masslinks语义一致，但这些局部核对不能替代D01要求。
4. **文档承认的装配风险尚未闭环。** 制造说明有1.25mm/0.85mm薄区、塑料螺纹咬合、胶接和试片要求，但未见实际打印、工具扫掠、拔出/胶接测试。文字具体有助于复核，不等于相关指标通过。
